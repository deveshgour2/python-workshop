# css(cascading style sheet):-

    css is used for styling a webpage
    css provides properties + values which make our page attractive.
=======================================================

## types of css:-

1. inline css:- inside the tag
2. internal css:- within a webpage
3. external css:- within a project

4. inline css:- css the tag
=> syntax  :- <tag style="property:value; property:value;...">
exp.

<p style="background:red">para tag</p>

====================================================

## css box model:-

    css box model is a collection of boxes.
    which design with <div> tag. it includes the properties like margin, padding, and inside padding we write content.
