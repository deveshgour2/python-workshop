# html:-

    html is a hypertext markup language it is a designing language used for design web page.

1. it is an error free language.
2. html page runs on browser
3. html easily integrated with any programming language like java, python etc.

# html tags:-

    it is written  in js and it has predefined meanings.
    html tag written inside angular brackets.

1. paired tag :- need opening and closing
2. unpaired tag :- need only opening

# DHTML :-

    dhtml provides tag by which we can take input from users at runtime.

types of controls:-

1. text control:-
    text, email, url, password, textarea

2. selection control:-
    date, number, radio button, checkbox, combo box, listbox

3. file control:-
    file

4. button control:-
    <button> <client side>
    reset <clear fields>
    submit <server side>

note:- all the control designed with the help of input tag except textarea, combobox and listbox. input is an empty tag and it has type property.
